Βλέπετε μια λειτουργία σε μια εφαρμογή που θέλετε να ενσωματώσετε στο δικό σας προϊόν; Ζητήστε από τον πράκτορά σας να την ερευνήσει με το REA. Μπορεί να εξετάσει την εφαρμογή χωρίς τον πηγαίο της κώδικα, να εξηγήσει πώς λειτουργεί η λειτουργία, να δείξει τα στοιχεία και να δημιουργήσει μια παρόμοια υλοποίηση για το έργο σας.

Το REA συνδέει τον πράκτορά σας με εργαλεία για την εξέταση εγγενών δυαδικών αρχείων, εφαρμογών JavaScript και Electron, συγκροτημάτων .NET και ιστοτόπων. Μπορείτε επίσης να χρησιμοποιήσετε τα ίδια εργαλεία από το τερματικό σας. Η ανάλυση εκτελείται τοπικά, και τα αποτελέσματα περιλαμβάνουν τα στοιχεία και τους περιορισμούς πίσω από κάθε συμπέρασμα.

Η εγκατάσταση καταχωρεί το REA στον πράκτορά σας και εγκαθιστά τις αντίστοιχες οδηγίες ροής εργασίας. Για εγγενή ανάλυση μπορείτε να χρησιμοποιήσετε μια υπάρχουσα εγκατάσταση Hopper, Ghidra ή IDA. Με τη συγκατάθεσή σας, η εγκατάσταση μπορεί προαιρετικά να εγκαταστήσει και το Hopper. Η στατική ανάλυση JavaScript δεν απαιτεί μηχανή εγγενούς ανάλυσης.

> **[Επισκεφθείτε τον ιστότοπο του REA](https://rea.tools/)** για οδηγίες εγκατάστασης, εικονογραφημένα εγχειρίδια και πραγματικές μελέτες περίπτωσης.

## Γρήγορη εκκίνηση

### Ρύθμιση του πράκτορά σας

Με εγκατεστημένα τα Node.js και npm, εκτελέστε:

```bash
npx rea-agents setup
```

Επιλέξτε τους πράκτορές σας, ελέγξτε τις προτεινόμενες αλλαγές και εγκρίνετέ τες. Η εγκατάσταση προσθέτει τον διακομιστή MCP του REA και τις αντίστοιχες οδηγίες ροής εργασίας, με αντίγραφα ασφαλείας των υπαρχόντων αρχείων ρύθμισης. Στη συνέχεια, επανεκκινήστε τον πράκτορά σας.

Η εγκατάσταση υποστηρίζει Claude Code, Codex, Cursor, Gemini CLI, Grok Build και [άλλους πράκτορες](../installation.md#supported-agents). Δείτε την [εγκατάσταση και ρύθμιση](../installation.md) για τη διαμόρφωση παροχέα και τη χειροκίνητη καταχώριση MCP.

### Ρωτήστε τον πράκτορά σας

```text
Κατανόησε πώς λειτουργεί η αναζήτηση στην εφαρμογή Notes, δείξε μου τα στοιχεία και δημιούργησε μια παρόμοια λειτουργία για το έργο μου.
```

Αντικαταστήστε το Notes με την εφαρμογή-στόχο σας και τη λειτουργία που θέλετε να κατανοήσετε.

### Χρήση του τερματικού

Εξετάστε έναν αποσυμπιεσμένο κατάλογο εφαρμογής JavaScript/Electron ή ένα αρχείο ASAR:

```bash
npx -y rea-agents@latest analyze-javascript-application /absolute/path/to/app --json
```

Το αποτέλεσμα περιλαμβάνει λειτουργικές μονάδες, εισαγωγές, όρια Electron και τα αντίστοιχα στοιχεία. Αντικαταστήστε τη διαδρομή με τον δικό σας στόχο, όπως π.χ. `"D:/apps/example"` στα Windows.

Για να εγκαταστήσετε την εντολή `rea` για τακτική χρήση:

```bash
npm install --global rea-agents
rea --help
```

Για εγγενή ανάλυση, διαμορφώστε πρώτα έναν παροχέα. Δείτε τον [οδηγό CLI και Στοιχείων](../cli.md) για εγγενείς εντολές, επιλογή παροχέα, στιγμιότυπα και σενάρια.

### Ενημέρωση του REA

Το REA αλλάζει γρήγορα, και οι νέες εκδόσεις περιλαμβάνουν συχνές διορθώσεις σφαλμάτων. Διατηρήστε την εγκατάστασή σας ενημερωμένη.

Για ένα CLI που έχει εγκατασταθεί με `npm install --global` ή `bun add --global`:

```bash
rea update
```

Οι καθολικές ενημερώσεις του Bun απαιτούν Bun 1.2.17 ή νεότερη έκδοση. Με μια παλαιότερη έκδοση Bun, αναβαθμίστε το Bun χειροκίνητα πριν εκτελέσετε `rea update`.

Για να ανανεώσετε τις καταχωρίσεις και τη δεξιότητα του πράκτορά σας, εκτελέστε την εντολή εγκατάστασης που εκτυπώνει η ενημέρωση.

Εάν χρησιμοποιείτε `npx`, ενημερώστε τη ρύθμιση του πράκτορά σας με:

```bash
npx rea-agents@latest setup
```

Ελέγξτε τις αλλαγές ρύθμισης και επανεκκινήστε τον πράκτορά σας. Για μεμονωμένες εντολές CLI, χρησιμοποιήστε `npx rea-agents@latest` ακολουθούμενο από την εντολή. Με το Bun, χρησιμοποιήστε `bunx rea-agents@latest` στη θέση του `npx rea-agents@latest`.

## Πώς λειτουργεί το REA

Ο πράκτοράς σας καλεί το REA μέσω MCP για να εξετάσει τον στόχο και να ιχνηλατήσει τον σχετικό κώδικα. Το REA επιστρέφει ευρήματα μαζί με τα στοιχεία τους. Ο πράκτορας τα χρησιμοποιεί για να κάνει διευκρινιστικές ερωτήσεις, να εξηγήσει τη συμπεριφορά ή να γράψει και να ελέγξει μια υλοποίηση. Οι εντολές CLI χρησιμοποιούν τις ίδιες ροές εργασίας.

<a id="choosing-a-deep-analysis-provider"></a>

Οι εγγενείς μορφές και η υποστήριξη συστήματος διαφέρουν ανάλογα με τον παροχέα. Δείτε τη [ρύθμιση Hopper και Ghidra](../installation.md#hopper), τον [οδηγό IDA](../ida-provider.md) (συμπεριλαμβανομένης μιας προαιρετικής εγγενούς γέφυρας MCP) και την [πειραματική υποστήριξη Ghidra για Windows](../windows-ghidra-p0.md). Το Ghidra υποστηρίζει επίσης [ανάλυση 16-bit DOS](../ghidra-dos.md). Για μεγάλα δυαδικά αρχεία, αυξήστε την προθεσμία εκκίνησης του παροχέα με `REA_GHIDRA_STARTUP_TIMEOUT_MS` ή `REA_HOPPER_STARTUP_TIMEOUT_MS`. Για την επιλογή παροχέα, δείτε τον [οδηγό CLI](../cli.md#choose-a-provider). Ελέγξτε τη [διαθεσιμότητα εκδόσεων](../installation.md#released-package-and-main) για λειτουργίες που προστέθηκαν μετά την τελευταία έκδοση στο npm.

## Παραδείγματα

[![Εικονογραφήσεις των παραδειγμάτων ηχητικής πανοραμικής μετατόπισης του DX-Ball, της γέφυρας προχείρου του Notion και του δακτυλίου σφαιρών του TH04](../assets/rea-showcases.png)](https://rea.tools/showcase/)

### DX-Ball: ανακατασκευή ενός υπολογισμού ηχητικής πανοραμικής μετατόπισης

Παρακολουθήστε μια κλήση ήχου μέχρι τη βοηθητική ρουτίνα μετατροπής θέσης σε πανόραμα, εξετάστε τις εντολές και μετατρέψτε έναν ελλιπή ψευδοκώδικα σε C. Η ανακατασκευή περνά 3.205 δοκιμές αρχικού x86 και αναπαράγει και τα 63 byte της μεταγλωττισμένης συνάρτησης.

[Διαβάστε τη μελέτη περίπτωσης](https://rea.tools/showcase/dx-ball/) · [Αποθετήριο ανακατασκευής](https://github.com/N0zoM1z0/dx-ball)

### Notion: ιχνηλάτηση της γέφυρας προχείρου του Electron

Εντοπίστε το API προχείρου του renderer, παρακολουθήστε το μέσω preload και IPC μέχρι την κύρια διεργασία και εξετάστε τη μορφή εμπλουτισμένου προχείρου.

[Διαβάστε τη μελέτη περίπτωσης](https://rea.tools/showcase/notion/)

### TH04: ανάκτηση ενός υπολογισμού δακτυλίου σφαιρών DOS

Εξετάστε τις 16-bit εντολές του αρχικού παιχνιδιού PC-98, ανακτήστε τους υπολογισμούς σταθερής και στοχευμένης γωνίας και συγκρίνετε την ανακατασκευασμένη C++ με την ιστορική έξοδο του μεταγλωττιστή.

[Διαβάστε τη μελέτη περίπτωσης](https://rea.tools/showcase/th04/) · [Αποθετήριο ανακατασκευής](https://github.com/N0zoM1z0/th04)

Εάν έχετε χρησιμοποιήσει το REA σε κάτι ενδιαφέρον, θα θέλαμε να το δούμε. Μοιραστείτε την περίπτωσή σας σε ένα [issue](https://github.com/morluto/rea/issues) ή ένα [pull request](https://github.com/morluto/rea/pulls), συμπεριλαμβάνοντας τον στόχο, την ερώτησή σας, πώς βοήθησε το REA και τι βρήκατε.

<details>
<summary><strong>Ποιοι πράκτορες μπορούν να χρησιμοποιήσουν το REA;</strong></summary>

Οποιοσδήποτε πράκτορας υποστηρίζει τοπικούς διακομιστές MCP. Η εγκατάσταση ρυθμίζει τους [υποστηριζόμενους πράκτορες](../installation.md#supported-agents)· άλλοι πελάτες μπορούν να χρησιμοποιήσουν τη [χειροκίνητη καταχώριση MCP](../installation.md#mcp-registry).

</details>

<details>
<summary><strong>Χρειάζομαι Hopper, Ghidra ή IDA;</strong></summary>

Για τη βαθιά εγγενή ανάλυση χρησιμοποιείται ένα από αυτά. Η στατική επιθεώρηση JavaScript και .NET λειτουργεί χωρίς μηχανή εγγενούς ανάλυσης. Η εγκατάσταση μπορεί να εγκαταστήσει το Hopper μετά από έγκριση· τα Ghidra και IDA χρησιμοποιούν τις υπάρχουσες εγκαταστάσεις σας. Δείτε τη [ρύθμιση παροχέα](../installation.md#hopper).

</details>

<details>
<summary><strong>Πρέπει να εκκινήσω πρώτα το Hopper;</strong></summary>

Το REA εκκινεί το Hopper όταν μια λειτουργία το χρειάζεται. Στο macOS, ένας διάλογος πρώτης εκτέλεσης μπορεί να σας ζητήσει να επιλέξετε λειτουργία επίδειξης ή να ενεργοποιήσετε την άδειά σας. Ολοκληρώστε αυτήν την προτροπή στην ίδια περίοδο σύνδεσης χρήστη πριν από την πρώτη σας λειτουργία CLI/MCP ή μια αυτοματοποιημένη εργασία. Ανοίξτε το Hopper χειροκίνητα εάν χρειάζεται. Δείτε την [εκκίνηση του Hopper και την αντιμετώπιση προβλημάτων](../installation.md#launcher-paths-and-troubleshooting).

</details>

<details>
<summary><strong>Τι κάνει η εγκατάσταση της δεξιότητας από το skills.sh;</strong></summary>

Η δεξιότητα παρέχει οδηγίες έρευνας στον πράκτορά σας. Χρησιμοποιήστε `npx rea-agents setup` για να καταχωρίσετε τον διακομιστή MCP του REA και να εγκαταστήσετε τις αντίστοιχες οδηγίες, και στη συνέχεια επανεκκινήστε τον πράκτορά σας. Δείτε την [εγκατάσταση μόνο της δεξιότητας](../installation.md#skill-only-installation).

</details>

<details>
<summary><strong>Τι κώδικα επιστρέφει το REA;</strong></summary>

Η εγγενής ανάλυση επιστρέφει ψευδοκώδικα και συμβολική γλώσσα. Η ανάλυση JavaScript/Electron ανακτά λειτουργικές μονάδες και τις σχέσεις τους. Ο πράκτοράς σας χρησιμοποιεί αυτά τα ευρήματα για να γράψει και να ελέγξει μια υλοποίηση· τα [παραδείγματα](#παραδείγματα) παρέχουν επεξεργασμένα δείγματα.

</details>

<details>
<summary><strong>Ανεβάζει το REA την εφαρμογή μου κάπου;</strong></summary>

Το REA αναλύει τους στόχους τοπικά. Ο πράκτοράς σας λαμβάνει τα αποτελέσματα των εργαλείων, και ο πάροχος μοντέλων του έχει τη δική του πολιτική δεδομένων.

</details>

<details>
<summary><strong>Τι πρέπει να κάνω αν αντιμετωπίσω κάποιο σφάλμα;</strong></summary>

Ενημερώστε πρώτα· μια πρόσφατη έκδοση μπορεί ήδη να το διορθώνει.

Για ένα CLI που έχει εγκατασταθεί με `npm install --global` ή `bun add --global`:

```bash
rea update
```

Για τη ρύθμιση πράκτορα μέσω `npx`:

```bash
npx rea-agents@latest setup
```

Εάν χρησιμοποιείτε κάποιον πράκτορα, ολοκληρώστε την [ανανέωση της ρύθμισης](#ενημέρωση-του-rea) και επανεκκινήστε τον. Δοκιμάστε ξανά την ίδια εργασία. Εάν το πρόβλημα παραμένει, [ανοίξτε ένα issue](https://github.com/morluto/rea/issues) με την έκδοση του REA, τον τύπο στόχου, τα βήματα αναπαραγωγής και την έξοδο σφάλματος.

</details>
